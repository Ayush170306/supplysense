# SupplySense: Intelligent Supply Chain Risk Prediction

SupplySense is a high-performance, microservices-based platform designed to predict and optimize supply chain resilience using Ensemble Learning and Explainable AI.

## 🚀 Advanced AI Features
* **Random Forest Ensemble:** Captures non-linear risk patterns across 8+ logistical variables.
* **Explainable AI (SHAP):** Provides mathematical transparency for every risk score generated.
* **SMOTE Integration:** Handles imbalanced datasets to accurately predict rare catastrophic disruptions.
* **FastAPI AI Engine:** High-concurrency microservice for sub-millisecond ML inference.

## 🛠 Tech Stack
* **Frontend:** React.js, Lucide Icons, Framer Motion (Aesthetic UI)
* **Backend:** Node.js, Express.js, MongoDB (MERN)
* **AI Service:** Python 3.10+, FastAPI, Scikit-learn
* **DevOps:** Docker Ready

## 📂 Project Structure
* `/frontend`: React dashboard with real-time analytics.
* `/backend`: API orchestration and user authentication.
* `/ml-service`: Python microservice serving the Random Forest model.
